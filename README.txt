CALCULADORA DE PAVIMENTOS - TECNOLOGICO COMFENALCO

Esta version es publica: no requiere contrasena ni registro.

Archivos principales:
- index.html: interfaz y SEO basico
- css/estilos.css: identidad visual y responsive
- js/app.js: motor de calculo y visualizacion
- logo-comfenalco.png: logo institucional proporcionado
- robots.txt y sitemap.xml: base para indexacion

Para publicar:
1. Subir todo el contenido del proyecto a un repositorio de GitHub.
2. Activar GitHub Pages desde Settings > Pages.
3. Reemplazar TU-DOMINIO.com en robots.txt y sitemap.xml por el dominio real.
4. Registrar el sitio en Google Search Console y enviar /sitemap.xml.

Nota: la herramienta conserva el motor de calculo existente y se presenta como herramienta academica/referencial.
